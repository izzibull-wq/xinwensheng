在 VS Code 中使用

1. 在 VS Code 中打开 xinwensheng 文件夹。
2. 安装 Live Server 扩展。
3. 右键 index.html → Open with Live Server 或点击右下角 Go Live。

如果没有声音怎么办？

1. 请用 Google Chrome / Microsoft Edge 最新版打开。
2. 点 测试注入语音，如果能听到“你好”，说明正常。
3. 本版本语音已注入，不用安装中文语音 — 只要有网络就能朗读。
4. 不要在聊天预览里测试，要下载 ZIP 用 Chrome + Live Server。
